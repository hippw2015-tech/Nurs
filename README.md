# سجل الورديات — مشروع APK آمن

## لماذا يبقى رمز الجهاز ثابتًا؟
رمز الجهاز يُشتق من معرّف أندرويد (ANDROID_ID)، وهو ثابت للجهاز الواحد **ما دام التطبيق موقَّعًا بنفس المفتاح**.
لذلك يُبنى التطبيق دائمًا بمفتاح التوقيع الثابت `signing/release.p12`. لا تحذفه ولا تغيّره، واحتفظ بنسخة منه: لو تغيّر ستتغير رموز كل الأجهزة. الرمز يبقى كما هو بعد إلغاء التثبيت وإعادته، ويتغير فقط عند إعادة ضبط المصنع.
**أبقِ المستودع Private** لأن المفتاح داخله.

## الخطوات
1. افتح `tools/license-tool.html` ← اكتب عبارة مرور سرية طويلة ← "اشتقاق المفتاح العام" ← استبدل السطر `const PUB=null;` في `www/index.html` بالناتج. نفس العبارة تعطي نفس المفتاح دائمًا، فاحفظها.
2. ارفع كل محتويات المجلد (مع `.github` و`signing`) إلى مستودع **خاص** على GitHub.
3. من Actions شغّل **Build APK** ونزّل `nursing-apk` وثبّته (إن ثبّتَّ نسخة قديمة مبنية قبل هذا التحديث فاحذفها أولًا).
4. عند أول فتح: ينسخ المستخدم رمز الجهاز ← توقّعه في الأداة ← يلصق الرقم ← ينشئ كلمة مرور.

## استعادة البيانات بعد إعادة التثبيت
من الإعدادات ← "حفظ / مشاركة" يُنشئ ملفًا مشفّرًا (`.nrs`) يحمل البيانات وترخيص الجهاز. بعد إعادة التثبيت اختر "استرجاع من نسخة احتياطية" في شاشة الدخول ثم أدخل كلمة المرور نفسها.
